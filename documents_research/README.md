# 研究・調査用の資料セット（書籍 第8章）

社内規程（`documents/`）とは別に、研究・調査の実例として使う資料セットです。テーマは「日本政府のSDGs（持続可能な開発目標）への取組」で、同じ主題を扱う公的文書を3点使います。

アプリはこのフォルダを、環境変数 `KIMITSU_DOCS` で指定して読みます。

```text
set KIMITSU_DOCS=%~dp0documents_research     （Windows・バッチファイル内）
python run.py
```

## 資料と入手先

外務省のサイトはプログラムからの自動ダウンロードを拒否する設定になっているため、ブラウザで開いて「名前を付けて保存」し、下の名前でこのフォルダに置いてください。

| 保存する名前 | 文書 | 発行 | 入手先 |
|---|---|---|---|
| SDGs実施指針_改定版_2023.pdf | 持続可能な開発目標（SDGs）実施指針 改定版（SDGs推進本部決定） | 2023年12月19日 | https://www.mofa.go.jp/mofaj/gaiko/oda/sdgs/pdf/kaitei_2023_jp.pdf |
| SDGs自発的国家レビュー_VNR_2025.pdf | SDGsに関する自発的国家レビュー（VNR）報告書（内閣官房・外務省） | 2025年6月10日 | https://www.mofa.go.jp/mofaj/gaiko/oda/sdgs/pdf/20250610_vnr.pdf |
| SDGs概要_外務省_2023.pdf | SDGsの概要（外務省） | 2023年5月 | https://www.mofa.go.jp/mofaj/gaiko/oda/sdgs/pdf/sdgs_gaiyou_202305.pdf |

いずれも政府の公開文書です。リポジトリには同梱せず、入手先のみ記載しています（利用条件は各文書と外務省サイトの規約に従ってください）。

## このフォルダの意味

前著の9.5と姉妹書のQ71が勧めた「目的別に資料を絞る」を、フォルダの切り替えで実現しています。社内規程に答えさせたいときは `documents/`、調査資料に答えさせたいときはこのフォルダ、というように、起動時に環境変数で選びます。索引のキャッシュ（`embed_cache.json`）はファイルの指紋をキーにしているので、切り替えても計算し直しにはなりません。
