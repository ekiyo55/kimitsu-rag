# サンプル資料の出典

このフォルダは、アプリが検索対象にする「参考書」の置き場です。実際に使うときは、ここに自分の資料（.docx / .pdf / .xlsx）を入れてください。

書籍『AIに機密情報を持たせる方法』の検証で使った規程は、上場準備中のスタートアップ企業の社内規程を想定して集めたもので、公的機関が公開しているひな型が中心です。一つは本書のために作った架空の規程で、社名・個人名が入らないよう、必要な箇所は「◯◯」に置き換えています。
